# 📊 Análisis y procesos comerciales

### 1. Diagnóstico del embudo de ventas
~~~
Estos son los datos de mi embudo del último trimestre: [leads captados, reuniones, propuestas enviadas, ventas cerradas, ticket medio y duración media del ciclo]. Calcula las tasas de conversión entre etapas, identifica el principal cuello de botella y propón 3 acciones concretas para mejorarlo, ordenadas por impacto.
~~~

### 2. KPI comerciales para escalar
~~~
Mi empresa vende [producto/servicio] con un equipo de [n] personas. Define los 8 indicadores comerciales más importantes que debería seguir cada semana: qué mide cada uno, cómo se calcula, un valor objetivo orientativo para mi sector [sector] y qué hacer si se desvía.
~~~

### 3. Previsión de ventas
~~~
Estas son mis oportunidades abiertas: [tabla con empresa, importe, etapa y fecha prevista de cierre]. Mis tasas de cierre históricas por etapa son: [porcentajes]. Calcula la previsión de ventas para los próximos 3 meses (escenario pesimista, realista y optimista) y señala qué oportunidades conviene priorizar.
~~~

### 4. Manual de ventas (playbook)
~~~
Ayúdame a crear el manual de ventas de mi empresa para que cualquier comercial nuevo pueda vender como el mejor. Vendemos [producto/servicio] a [cliente ideal]. Nuestro proceso actual es: [describe los pasos]. Estructura el manual con: cliente ideal, propuesta de valor, etapas del proceso con criterios de avance, guiones y plantillas, objeciones frecuentes y métricas.
~~~

### 5. Automatizaciones para el equipo comercial
~~~
Usamos estas herramientas: [CRM, correo, calendario, hojas de cálculo…]. Nuestras tareas comerciales repetitivas son: [lista]. Propón 6 automatizaciones (con IA o herramientas no-code) que liberen tiempo al equipo, indicando la herramienta, cómo funcionaría, las horas semanales ahorradas y la dificultad de implantación.
~~~
